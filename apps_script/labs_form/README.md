# Структурированная форма ввода занятий (Apps Script)

Боковая панель внутри Google Sheets, которая заменяет ручной ввод занятий
кнопками + выпадающими списками. Тётка-расписание:

1. Кликает на ячейку в таблице.
2. Открывает «Расписание → Добавить / редактировать занятие».
3. Жмёт нужный тип (Лекция / ЛБ / ПЗ / Семинар / Куратор / ДО), выбирает
   предмет и препода из выпадающего списка, при необходимости — подгруппу,
   аудиторию, дату-заметку.
4. Жмёт «Применить» — ячейка автоматически заполняется правильным форматом
   (цвет фона, жирный шрифт предмета, переносы строк, аудитория справа).

Если ячейка уже заполнена и она кликает на неё → форма открывается **с её
данными**, можно поправить и применить.

---

## Что нужно для установки

- Доступ владельца/редактора к Google Spreadsheet с расписанием (та самая
  книга `1itE56-6GQvK2MvNBBtos2O7sGFGD0pC7zpWM4CV2OnU` с листами year1/year2/year3).
- Один скрипт ставится на **один Spreadsheet**. У нас все три года — в одной
  книге, поэтому одной установки хватит на все три.

---

## Установка (один раз, ~5 минут)

1. Открой нужный Google Spreadsheet.
2. **Расширения → Apps Script** (Extensions → Apps Script).
3. Откроется новая вкладка с пустым проектом. В левой панели:
   - В файле `Код.gs` (Code.gs) удали всё его содержимое и вставь содержимое
     [Code.gs](./Code.gs) из этого репозитория.
   - Добавь файл «HTML», нажав «+» рядом с «Файлы» → «HTML». Назови `Sidebar`
     (без `.html`). Вставь содержимое [Sidebar.html](./Sidebar.html).
4. Жми **сохранить** (💾 или Ctrl+S).
5. Вернись в Spreadsheet и **обнови страницу** (Ctrl+R / F5). В меню сверху
   должен появиться пункт **«Расписание»**.
6. При первом запуске Google попросит разрешения — нажми «Дополнительно» →
   «Перейти к проекту (небезопасно)» → «Разрешить». Это нужно потому, что
   скрипт читает и пишет в твою же таблицу.

Готово. Теперь в любой ячейке таблицы тыкаешь, открываешь меню «Расписание»,
и работаешь через форму.

---

## Первая инициализация словарей

Сразу после установки в выпадающих списках предметов / преподов / аудиторий
будет пусто. Чтобы заполнить — один раз нажми
**«Расписание → 🔄 Пересоздать справочник из таблицы»**. Скрипт пройдётся по
всем листам книги, выдернет уникальные предметы (по жирному шрифту),
преподов (по префиксам `доц./ст.пр./асс.`) и аудитории (по числовому
формату) и сложит их в скрытый лист «Справочники».

Дальше:

- Когда в форме выбираешь новый предмет / препода / аудиторию — он
  автоматически добавляется в «Справочники».
- Если что-то записалось криво — открой лист «Справочники» (через меню
  «📋 Открыть справочник») и поправь руками. Это обычная таблица.

## Структура ячейки после применения

Форма пишет в **две соседние ячейки**:

| ячейка | что лежит |
|---|---|
| Активная (lesson cell) | **Предмет** (жирным), подгруппа, преподаватель(и), заметка (курсивом, если есть) |
| Соседняя справа (room cell) | Аудитория(и). При лабе с несколькими подгруппами — несколько строк |

Цвет фона обеих ячеек — по типу занятия.

Это совпадает с тем, как заполняют расписание сейчас, поэтому существующие
ячейки можно открывать и редактировать формой без перевёрстки.

---

## Особенности по типам

- **Лекция / Практ. / Семинар / Куратор / ДО** — одна подгруппа (можно
  выбрать комбинацию `1ПГ/2ПГ/3ПГ` чекбоксами + чёт/нечёт).
- **ЛБ (лабораторная)** — мульти-блок с подгруппами. У каждой подгруппы —
  свой препод и своя аудитория, как и сейчас в реальных таблицах.

## Что делать, если что-то пошло не так

| Проблема | Решение |
|---|---|
| Меню «Расписание» не появилось после обновления страницы | Открой Apps Script (Extensions → Apps Script), убедись что есть оба файла `Code.gs` и `Sidebar.html`. Если есть — запусти `onOpen` вручную (выбери функцию `onOpen` в выпадающем списке сверху, нажми «Запустить»). |
| Sidebar открывается, но без кнопок | Проверь, что файл `Sidebar` называется **именно `Sidebar`** (без расширения, чувствительно к регистру). |
| Форма не сохраняет в ячейку | Проверь, что выбрана нужная ячейка (она подсвечена в Google Sheets). После клика по форме фокус должен оставаться на ячейке. |
| Скрипт жалуется на разрешения | Apps Script → ⚙ Project Settings → проверь, что Google Sheets API включён. Обычно включается автоматически при первом запросе. |
| Хочу откатить — удалить скрипт | Apps Script → правый клик на `Code.gs` → «Удалить». Все данные в таблице останутся, скрипт просто отключится. |

## Где живут словари (для разработчика)

Словари инициализируются автоматически из существующих данных таблицы
(меню «Пересоздать справочник из таблицы»). Если нужны стартовые JSON-ы
для другой таблицы — они есть в [`dictionaries/`](./dictionaries/) (извлечены
из последнего `public/schedule.json`).

`extract.py` пересобирает их из текущего `public/schedule.json` (используется
при обновлении репо, не для конечного пользователя).

---

## Что эта форма даёт парсеру (`schedule_parser/parse_schedule.py`)

**Ничего нового парсить не надо.** Форма пишет в ячейку **тот же формат**,
который парсер уже умеет читать:

- Цвет фона → `lesson_type` (уже реализовано в `lesson_type_resolver.py`).
- Жирный шрифт → `subject` (уже реализовано в `rich_sheet.py`).
- Многострочный текст → `teacher` / `subgroup` / `notes` (уже реализовано).
- Соседняя ячейка справа → `rooms` (уже реализовано).

Единственное различие — данные становятся **единообразными**, без
свободного текста «от руки», и парсер перестаёт спотыкаться на лабах.
